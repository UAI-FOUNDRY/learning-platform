# Platform Workflows

## 1. Learner Journey
1. Discovery & Browsing via Course Catalog.
2. Enrollment in selected courses.
3. Engaging with sections, lectures, and multimedia content.
4. Completing interactive assessments (quizzes and assignments).
5. Course completion and certificate generation.
6. Submitting course ratings and reviews.

## 2. Instructor Journey
1. Instructor profile setup.
2. Course creation and curriculum structuring (sections and lectures).
3. Assessment authoring (quiz builder and assignment builder).
4. Submitting course for administrative approval.
5. Reviewing learner submissions and course analytics.

## 3. Administrative Review & Approval
1. Submission received in Admin Dashboard.
2. Course evaluation (reviewing content, curriculum, and structure).
3. Status transition: `APPROVED`, `CHANGES_REQUIRED`, or `REJECTED`.
4. Platform management (categories, users, organizations, and reports).
