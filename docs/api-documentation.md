# API Documentation

## Base URL
`/api/v1`

## API Endpoints Overview
- **Authentication**: `/api/v1/auth` (Register, login, token refresh, verification)
- **Users**: `/api/v1/users` (Profile details, account updates)
- **Organizations**: `/api/v1/organizations` (Organization directory and memberships)
- **Courses**: `/api/v1/courses` (Catalog discovery, details, course management)
- **Categories**: `/api/v1/categories` (Category list and management)
- **Enrollments**: `/api/v1/enrollments` (User enrollments and access records)
- **Progress**: `/api/v1/progress` (Lecture completion status and metrics)
- **Quizzes**: `/api/v1/quizzes` (Quiz retrieval, attempts, evaluation)
- **Assignments**: `/api/v1/assignments` (Assignment details and learner submissions)
- **Certificates**: `/api/v1/certificates` (Certificate issuance and verification)
- **Reviews**: `/api/v1/reviews` (Course ratings and textual reviews)
- **Admin**: `/api/v1/admin` (Approval workflows, platform operations, statistics)
