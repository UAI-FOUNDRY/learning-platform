# Development Guidelines

## General Principles
1. **Separation of Concerns**: Keep business logic in `services/`, endpoint handling in `api/`, and UI components isolated.
2. **No Hardcoded Secrets**: Use `.env` for all sensitive configurations.
3. **Descriptive Naming**: Use clear, semantic names for files, components, and functions.
4. **Clean Code**: Follow PEP 8 for Python and standard ESLint/Prettier rules for React.
5. **Brand Agnostic**: Do not introduce unconfirmed brand names or placeholder brands.
